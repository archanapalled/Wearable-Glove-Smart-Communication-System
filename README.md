# Smart Gloves Communication System

## Project Overview
The Smart Gloves Communication System is an assistive technology project designed to help people with speech and communication difficulties communicate through hand gestures.

## Objective
To detect finger movements using flex sensors and display corresponding messages on an LCD.

## Technologies Used
- Arduino Nano
- Arduino IDE
- Embedded C / Arduino Programming

## Hardware Components
- Arduino Nano
- Flex Sensors (4)
- 16x2 LCD with I2C module
- LED
- DFPlayer Mini
- SD Card
- Speaker

## Working Principle
1. Flex sensors detect finger movements.
2. Arduino reads the sensor values through analog input pins.
3. Based on predefined threshold values, the corresponding message is identified.
4. The message is displayed on the LCD.
5. An LED indicates selected gesture conditions.
